Attention can gather “Alexander”, “the”, “Great”, but who that is lives in the weights. Engram takes static patterns off attention and FFN; it doesn’t replace them.

Our synthesis of the paper’s argument (§1, §6.1). Engram’s gate itself uses the hidden state that attention produced.

Attention is open-book search over the text you were handed. FFN is recall by computation. Engram is a dictionary with an index: the tokens give you the page number directly.
