4.4 · DOMAIN Q&A AND CUSTOMER SERVICE

Domain Q&A and customer service: value and limits

Potential value

  • A base model with Engram may be stronger overall, including on long context
  • Product names and set phrases fit its local patterns
  • No extra context tokens or retrieval service

Limits

  • No source citations, a compliance problem
  • Updates need training: bad for prices, stock
  • Sensitive to rephrasing
  • No released training code

Question → RAG (daily index, citations) → base model (Engram or not: decide by testing) → LoRA / fine-tuning for tone and flow

Recommended architecture: keep RAG as the knowledge layer. Whether the base model includes Engram should be decided by measurement, which is what Experiment D starts on.
