2.4 · CONTEXT-AWARE GATING

Context-aware gating: the hidden state decides

k = W_K · e v = W_V · e
α = σ( RMSNorm(h)ᵀ RMSNorm(k) / √d ) out = α · v

One number per token

The gate is a scalar per token and branch, not per dimension.

Multi-branch

With mHC (4 branches): shared table and W_V, one W_K per branch.

In code, not paper

A signed square root before the sigmoid, “matching the training kernel” (V4.1).

Paper §2.3–2.4; demo and V4.1 code. Without gating, about 89% of the validation-loss gain remains (Figure 5, read off the plot).

h is the hidden state after preceding attention, so it carries context; e is the retrieved memory. If memory contradicts context the gate goes toward zero, which also suppresses collision noise and polysemy.
