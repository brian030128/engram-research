What the demo implements, and what it doesn’t

Implemented

  • Tokenizer compression
  • Multi-head hashing, prime tables
  • Gating with signed sqrt
  • Per-branch keys
  • Short convolution

Missing or mocked

  • Attention, MoE, mHC: mocked
  • Loss, optimizer, training loop
  • Zero-init conv (paper says zero)
  • Table sharding, offload, prefetch
  • Pre-trained weights

We ran it unmodified on CPU: 16.9 s, 6.39 GB peak, 667M parameters per Engram module.

Only change: tokenizer loaded locally with trust_remote_code=False. Measured conv weight mean |w| ≈ 0.25 at init.

From reading the code, hash IDs come from NumPy and are never moved to the model’s device, so a GPU run would likely fail; we didn’t test that. Community PRs 13 to 15 address caching and vectorization but are unmerged.
