The idea: a built-in phrase lookup table

MoE: more experts

Consult a few experts per token

The input must be understood first to know whom to ask. Good at context-dependent work.

Engram: a lookup table

Read a few rows per token

The last 2–4 tokens give the row addresses directly. The model then decides whether the rows fit the context.

Complementary: most of the spare budget to experts and a small share to the table beats giving it all to experts.

Exam analogy: the original model derives every formula from scratch; Engram puts a formula sheet on the desk. The table stores vectors that represent a phrase’s meaning, not text.
