4.3 · UPDATING MEMORY INDEPENDENTLY

Can Engram memory be updated on its own?

Short answer: storage can be separated, but knowledge can’t be edited directly. It needs training, and the paper doesn’t test it.

QuestionAnswer
Tested in the paper?No; only joint training is described
Write one fact directly?No: rows are trained vectors shared by many n-grams
Train only the table, backbone frozen?Possible in principle; one third-party report
Side effects on other knowledge?Likely, since rows are shared

ENGRAFT (third party, unverified): on Qwen3.8-Flash-Next, training table rows only gave 0.841 exact answers on 841 held-out sentences (base 0.005). It failed across languages, and only 4 of 83 two-fact questions got both right.

Engram issue #26 and github.com/fulvian/engraft-ngram. Not peer reviewed, built with Claude Code, nothing measured on V4.1; we have not reproduced it.

The paper uses the word editable only for non-parametric memory such as REALM and RETRO, not for Engram. Experiment E tests updates directly against RAG and LoRA.
