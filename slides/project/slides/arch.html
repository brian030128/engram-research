1.1 · DENSE TRANSFORMER, MOE AND ENGRAM

Dense vs MoE vs Engram

　DenseMoEEngram (on MoE)
Scales byWider, deeperMore routed expertsMore table rows
Active per tokenAll parametersShared + top-k expertsFixed rows + projections
Selected by—Hidden state at run timeToken IDs, known in advance
Sparsity typeNoneConditional computationConditional memory
Best atGeneral computationContext-dependent workLocal, static, frequent patterns
Main limitCapacity tied to computeRouting, expert communicationLocal keys, hash collisions

Conditional computation activates part of the computation; conditional memory retrieves part of a stored representation.

Engram is added on top of an MoE backbone, not instead of it. The paper’s Engram-27B is MoE-27B with some routed experts swapped for an Engram table.
