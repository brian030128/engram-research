1 · BACKGROUND

Bigger models are stronger, and costlier

Dense

Twice the parameters, twice the compute

Capacity and cost are tied together.

MoE

Many parameters, few used per token

Standard in frontier models, but every input is still handled by computation.

The gap

No way to look things up

Some content needs no computing, only recalling.

Language mixes two kinds of work: reasoning (understanding, composing, calculating) and static recall (names, places, set phrases).

Dense models tie capacity to compute. MoE broke that link by activating only a few experts per token, which is why it became standard. The paper’s observation: MoE is still only conditional computation; Transformers have never had a native lookup operation.
