Multi-head hashing: too many n-grams for one row each

9.7 × 10¹⁴

possible 3-grams (99,092³)

~16 million

rows per head (V4.1)

mix = (x′t × m0) XOR (x′t−1 × m1) XOR … row = mix mod prime_head

Cost: many n-grams share a row and their vectors blend.

Fix 1: 8 heads give 8 addresses, rarely all taken by one rival.

Fix 2: the gate suppresses rows that don’t fit.

In both official codebases the 8 heads share one mix value and differ only by prime modulus (paper §2.2: “K distinct hash heads”).

Each table size is a distinct prime, chosen in order and never reused. The multipliers differ per layer.
