2.6 · CORE DATA FLOW

Walkthrough: what happens at the token “Great”

Sentence: Only Alexander the Great could tame the horse.

StepWhat it doesIn this example
1 · Last few tokensTake the n-grams ending here“the Great”, “Alexander the Great”
2 · AddressesHash each n-gram8 row addresses per n-gram
3 · Read rowsFetch and concatenateOne memory vector
4 · Ask the contextCompare with the hidden state: a 0–1 scoreContext is about a person: high
5 · Add it inMemory × score, added to the stateModel knows early who this is

In “the Great Wall”, a person-like memory doesn’t fit, so step 4 scores it low.

The paper’s Figure 7 shows the gate peaking at the end of phrases such as “Alexander the Great” and “the Milky Way”.

Step 4 is context-aware gating. Because the table only sees the last few tokens, it can return rows that don’t fit or that are mixed with other n-grams; the gate lets the model decide how much to use. Attention and MoE then run as usual.
